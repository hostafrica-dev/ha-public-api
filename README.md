HostAfrica’s Public API provides reliable, programmatic control over VPS services with a broad set of industry-standard API developer tools. As well as a RESTful API we provide a CLI and SDKs for a variety of languages as automation building blocks and a streamable MCP server for agent-driven, context-aware automation.

Authentication is token-based and all endpoints require a Bearer token in the Authorization header:
```
Authorization: Bearer <your-token>
```

The API base URL is https://api.hostafrica.com

Please see the [API reference documentation](https://api.hostafrica.com/docs/index.html) for more information.
